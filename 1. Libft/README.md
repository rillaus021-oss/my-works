# Libft

## Description

Libft is a C static library (`libft.a`) written for the 42 curriculum.
It implements common character, string, memory, conversion and output
functions and provides a bonus linked-list API.

The library contains **34 mandatory functions** and **9 bonus functions**.
Its purpose is to learn pointer manipulation, memory allocation, reusable
code, and how to build a static library.

### Library contents

**Character tests and case conversion:** `ft_isalpha`, `ft_isdigit`,
`ft_isalnum`, `ft_isascii`, `ft_isprint`, `ft_toupper`, `ft_tolower`.

**Strings and memory:** `ft_strlen`, `ft_memset`, `ft_bzero`, `ft_memcpy`,
`ft_memmove`, `ft_strlcpy`, `ft_strlcat`, `ft_strchr`, `ft_strrchr`,
`ft_strncmp`, `ft_memchr`, `ft_memcmp`, `ft_strnstr`, `ft_strdup`.

**Conversions and allocation:** `ft_atoi`, `ft_calloc`, `ft_itoa`.

**String creation and iteration:** `ft_substr`, `ft_strjoin`, `ft_strtrim`,
`ft_split`, `ft_strmapi`, `ft_striteri`.

**Output to file descriptors:** `ft_putchar_fd`, `ft_putstr_fd`,
`ft_putendl_fd`, `ft_putnbr_fd`.

**Bonus linked lists:** `ft_lstnew`, `ft_lstadd_front`, `ft_lstsize`,
`ft_lstlast`, `ft_lstadd_back`, `ft_lstdelone`, `ft_lstclear`,
`ft_lstiter`, `ft_lstmap`.

## Instructions

Run these commands in the Libft directory:

```sh
make          # Build mandatory functions into libft.a
make bonus    # Add the linked-list functions
make clean    # Delete object files
make fclean   # Delete object files and libft.a
make re       # Rebuild the mandatory library
```

Use the library in another C program:

```c
#include "libft.h"

int main(void)
{
    ft_putendl_fd("Hello, Libft!", 1);
    return (0);
}
```

Compile your program with the library:

```sh
cc -Wall -Wextra -Werror main.c -L. -lft -o example
./example
```

The source files and `libft.h` belong in the root of the Libft submission.
`libft.a` is generated by `make`; it is not included in the source archive.
